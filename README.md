# Expense Tracker

A Python command-line application for tracking and managing personal expenses.

## Features

- Add expenses
- View all expenses
- Calculate total spending
- Delete expenses
- Search expenses by category
- Calculate totals by category
- Search expenses by date
- Edit existing expenses
- Sort expenses by cost
- Validate user input
- Save and load expense data using JSON

## Project Structure

- `main.py` — Handles the menu and user interaction
- `expense_utils.py` — Contains expense-management logic and JSON save/load functions
- `expenses.json` — Stores saved expense data

## How to Run

Make sure Python 3 is installed.

Run:

```bash
python3 main.py
```

## Technologies

- Python
- JSON
- File I/O
